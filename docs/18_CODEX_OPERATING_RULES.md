# CODEX OPERATING RULES — sommerhusOrden

Use this file as standing instructions for all Codex work on sommerhusOrden.

## Core rule
Do not optimize for impressive breadth. Optimize for a working, maintainable iOS app that can realistically reach App Store.

## Always do
- Keep scope small.
- Prefer Apple-native frameworks.
- Keep Swedish UI copy concise.
- Keep all user-facing data editable by all family members in MVP.
- Keep docs updated when architecture or behavior changes.
- Run build/tests when claiming work is done.
- Report exact command results.

## Never do without explicit instruction
- Add custom backend.
- Add Firebase/Supabase.
- Add custom login/passwords.
- Add analytics/ads.
- Add push notifications.
- Add barcode scanning.
- Add AI/photo recognition.
- Add Android/web support.
- Add role-based permissions.
- Add multiple cottages.
- Add recipes or meal planning.

## If blocked
Do not invent success. Report:
- what was attempted
- exact error
- smallest next action for Mikkel
