# Definition of Done — sommerhusOrden

A feature is done only when:

- It is implemented in Swift/SwiftUI.
- It matches the product requirements.
- It has reasonable empty/error states.
- It does not introduce unnecessary dependencies.
- It has relevant tests where practical.
- The project builds successfully.
- The changed behavior has been manually verified.
- Documentation is updated if architecture/data model changed.

## MVP is done when
- Stays can be created, edited, listed, and capacity-checked.
- Max bed spaces defaults to 10 and can be changed in Settings.
- Each family stay can specify how many people are actually coming.
- Inventory can be searched and updated.
- Shopping list works across add/complete/delete flows.
- Data syncs across devices through iCloud/CloudKit or the chosen Apple-native sync approach.
- App has basic App Store readiness files/checklist.
- Privacy policy draft exists.
- Tests pass.
- Release build succeeds.
